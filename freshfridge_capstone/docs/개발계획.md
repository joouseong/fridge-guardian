# FreshFridge 개발 계획

## 1단계 - 기획 및 DB 설계
- 프로젝트 주제 확정
- 기능 요구사항 정의
- 화면 구성 설계
- ERD 설계
- MySQL 데이터베이스 생성

## 2단계 - 회원 기능
- 회원가입
- 로그인
- 로그아웃
- 비밀번호 암호화
- 로그인 사용자 세션 유지

## 3단계 - 식재료 관리
- 식재료 등록
- 식재료 조회
- 식재료 수정
- 식재료 삭제
- 사진 업로드
- 냉장/냉동/실온 구분

## 4단계 - 유통기한 관리
- 유통기한 D-Day 계산
- 3일 이내 임박 표시
- 만료된 식재료 표시
- 유통기한 기준 정렬

## 5단계 - 검색 및 필터
- 식재료 이름 검색
- 카테고리 검색
- 보관 위치 검색
- 유통기한 상태별 필터

## 6단계 - 레시피 추천
- 레시피 데이터베이스 구축
- 레시피별 필요 재료 저장
- 사용자 보유 식재료와 비교
- 재료 일치율 계산
- 일치율 순 추천

## 7단계 - 디자인 및 테스트
- PC/모바일 반응형 디자인
- 회원 기능 테스트
- CRUD 테스트
- 유통기한 계산 테스트
- 레시피 추천 테스트
- 잘못된 입력 처리

## 8단계 - 추가 기능
- AI 레시피 생성
- 식재료 사진 인식
- 가족 공유
- 알림 기능
- 통계 기능
