# STEP 6 — 레시피 데이터 구축

## 구현 목적
재고 기반 추천을 API 키 없이도 사용할 수 있도록 공통 레시피 16개를 준비합니다.

## 파일과 전체 코드
[V2__seed_recipes.sql](../backend/src/main/resources/db/migration/V2__seed_recipes.sql)에 모든 레시피와 필요 재료를 작성했습니다.

## 코드 설명
김치찌개, 김치볶음밥, 계란말이 등 가정 요리의 설명과 조리 순서를 직접 작성했습니다.
기본 수량은 2인분이며 영양값은 1인분당 예시 추정치입니다. 공인 영양 DB에서 가져온 수치는 아닙니다.
조리용 물은 기본 환경으로 간주하지만 소금·기름·양념은 재고 비교에 포함합니다.
Flyway가 최초 한 번만 실행하여 서버를 재시작해도 중복 데이터가 생기지 않습니다.

## 실행 방법
MySQL을 실행한 뒤 백엔드를 시작하면 V2 마이그레이션으로 데이터가 저장됩니다.
로그인 후 다음 단계의 /api/recipes/recommendations로 조회합니다.
