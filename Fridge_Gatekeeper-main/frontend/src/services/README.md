# API 통신

`api.js`는 인증, 식재료, 대시보드, 레시피, 요리 도우미의 REST API를 호출합니다.

요청에는 세션 쿠키를 포함하며, 변경 요청은 CSRF 토큰을 발급받아 전송합니다. 토큰이 만료된 경우 한 번 갱신하여 재시도하고, 401 응답은 로그인 화면으로 연결합니다. 통신 실패·잘못된 응답·요청 시간 초과는 화면에서 다시 시도할 수 있는 오류로 처리합니다.

개발·미리보기 서버는 `/api`를 백엔드에 전달합니다. 루트 `.env`의 `SERVER_PORT`를 반영하고, 별도 서버가 필요하면 `API_PROXY_TARGET`으로 주소 전체를 지정할 수 있습니다. 이 설정은 Vite 서버에서만 읽습니다. OpenAI API 키는 프론트엔드에 저장하거나 노출하지 않습니다.

요청·응답 형식은 [REST API 계약](../../../docs/api.md)을 참고하세요.
