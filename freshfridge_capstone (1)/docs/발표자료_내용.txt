[프로젝트명]
FreshFridge - 냉장고 식재료 관리 및 레시피 추천 웹서비스

[개발 배경]
냉장고에 어떤 식재료가 남아 있는지 기억하지 못하거나,
유통기한을 놓쳐 식재료를 버리는 문제를 해결하기 위해 기획했습니다.

[목표]
1. 냉장고 식재료를 체계적으로 관리한다.
2. 유통기한이 가까운 재료를 빠르게 확인한다.
3. 보유 식재료를 활용할 수 있는 레시피를 추천한다.
4. 식재료 낭비를 줄인다.

[핵심 기능]
회원가입/로그인
식재료 CRUD
사진 등록
D-Day 자동 계산
유통기한 임박 알림
검색/필터
레시피 추천
레시피 재료 일치율 계산

[사용 기술]
Node.js / Express / EJS / CSS / JavaScript / MySQL

[데이터베이스]
users
ingredients
recipes
recipe_ingredients

[기대효과]
식재료 관리 편의성 향상
음식물 낭비 감소
자취생 및 일반 가정의 식단 관리 편의성 향상
