# 프로젝트 비교: 팀원 프로젝트 vs Fridge Guardian

> 작성일: 2026-09-30. 각 폴더의 README, 개발계획, 소스 파일을 직접 확인해 정리했습니다.
> 확인하지 못한 것(팀원이 저장소 밖에 따로 가진 자료 등)은 "미확인"으로 표시했습니다.

## 1. 한눈에 보기

| 폴더 | 누가/무엇 | 스택 | 상태 |
|---|---|---|---|
| `freshfridge_capstone` | 팀원 캡스톤 **초기 버전** | Node · Express · EJS · MySQL | 합치기 전 원본 |
| `freshfridge_capstone (1)` | 팀원 캡스톤 **최신 버전** | 위와 같음 + Passport, Aiven, Vercel | 배포까지 완료 |
| `Fridge_Gatekeeper-main` | 다른 팀원의 프로젝트 | Java 21 · Spring Boot · React · MySQL | 합치기 전 원본 |
| **`Fridge_Guardian`** | 위 둘을 합쳐 새로 만든 프로젝트(이 저장소의 주 작업물) | Java 21 · Spring Boot 4.1 · React 19 · MySQL 8 | 로컬 동작·테스트 완료, 배포 전 |

`Fridge_Guardian`의 뼈대는 `Fridge_Gatekeeper-main`이고, `freshfridge_capstone`에서는 PRD 샘플 레시피의 조리 순서, 이미지 업로드 규칙, 일치율 계산, 발표 자료를 가져왔습니다. Node/EJS 코드는 재사용하지 않았습니다. (자세한 내용은 `DESIGN.md` 1장)

## 4. Fridge Guardian만의 차별점

1. **개인화**: 알레르기·비선호 재료·매운맛 한도로 추천 목록을 걸러 줍니다. AI 레시피에도 같은 조건이 적용됩니다.
2. **AI 레시피 생성**: 선택한 재료로 새 레시피를 만들고, 서버가 스키마·길이·알레르기 포함 여부를 다시 검사합니다. 이메일·회원 번호는 AI에 보내지 않습니다.
3. **부족 재료 → 장바구니 → 쇼핑 링크**: 추천 레시피에서 모자란 재료를 한 번에 담고 구매 링크로 이어 줍니다.
4. **자동 유통기한 알림**: 매일 자정 배치가 임박·만료 재료 알림을 만들고, 중복 알림을 막습니다.
5. **JWT 기반 인증 + 소셜 로그인**: 모바일·별도 프런트 배포에 맞는 구조입니다.
6. **사진·메모·바코드 등록**: 재료 입력 부담을 줄입니다.
7. **Windows·Mac 모두 같은 명령으로 실행**하고 CI로 검증할 수 있게 구성했습니다.

## 5. Fridge Guardian의 약점과 남은 과제

| 약점 | 설명 | 다음 단계 |
|---|---|---|
| 배포 안 됨 | 팀원 프로젝트는 주소로 접속 가능, Guardian은 로컬에서만 동작 | 배포 방식 결정 (`작업기록_및_다음단계.md` 4-3, 3-8) |
| 소셜 로그인 미동작 | 코드는 완료, Google/카카오 키와 Redirect URI 등록이 없음 | 팀원에게 등록 요청 후 `npm run setup:social` |
| AI 꺼져 있음 | OpenAI 키 없음 | 키 발급 후 `npm run setup:openai` |
| 재료별 아이콘 없음 | 사진이 없으면 모든 재료가 같은 냉장고 그림으로 표시됨. 팀원이 준비한 아이콘 자료는 이 저장소에서 **찾지 못함(미확인)** | 팀원에게 아이콘 파일을 받거나, 재료 이름별 이모지·SVG 매핑 추가 |
| Windows 실기 미검증 | 공통 실행 스크립트를 Mac에서만 실행해 봄 | Windows에서 `npm run verify`·`npm run dev` 확인, CI |
| 로컬 DB는 각자 별개 | 팀원끼리 회원·재고 데이터가 공유되지 않음 | 데모용 시드 데이터 또는 배포용 공용 DB |

## 6. 발표·설명용 한 줄 요약

> 초기 캡스톤(Node)의 재고·레시피 기능과 Gatekeeper(Spring)의 추천 엔진을 합치고,
> **개인화 · AI 레시피 · 장바구니 · 자동 알림 · JWT/소셜 로그인**을 더한 통합 프로젝트입니다.
> 남은 것은 **배포**와 소셜·AI 키 연결, 재료별 아이콘입니다.
