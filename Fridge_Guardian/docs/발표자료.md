# 발표 자료 — 냉장고 문지기 (Fridge Guardian)

> 한 줄 설명: "냉장고 속 식재료의 유통기한을 관리하고, 보유 재료로 만들 수 있는 레시피를 추천·생성하여 음식물 낭비를 줄이는 웹 서비스입니다."
> (`freshfridge_capstone/docs/발표자료_내용.txt`의 기획을 이어받아 확장했습니다.)

## 1. 문제와 해결

- **문제:** 냉장고에 무엇이 남았는지 잊고 유통기한을 놓쳐 버리는 일이 잦고, 남은 재료로 무엇을 만들지 고민합니다.
- **해결:** 재료·유통기한·사진을 등록하면 임박한 재료를 먼저 보여 주고(D-Day 배지, 자정 알림), 보유 재료로 만들 수 있는 레시피를 **일치율(%)**로 추천하며, 원하면 **AI가 선택한 재료로 맞춤 레시피**를 만들어 줍니다. 부족한 재료는 쇼핑 링크나 장바구니로 이어집니다.
- **대상:** 1인 가구, 요리 초보자, 유통기한 관리가 필요한 사용자.

## 2. 핵심 기능 (시연 순서)

1. 회원가입(6자 이상·확인 일치) → 로그인 / Google·Kakao 소셜 로그인
2. 식재료 등록: 목록 선택·붙여넣기 일괄 등록, 사진·메모·**바코드 스캔**
3. 대시보드: 전체/임박/만료 요약 + 유통기한이 가장 가까운 6개 카드(D-5, D-0, D+2)
4. 검색·카테고리·보관 위치·상태 필터와 초기화
5. 레시피 추천: 일치율, ✓/부족 재료, **BEST MATCH**, 난이도·시간·조리법
6. 내 설정(알레르기·비선호·매운맛) → 추천 목록 자동 필터
7. 부족한 재료 → 쿠팡·마켓컬리 링크 / 장바구니 자동 담기
8. AI 레시피 생성(재료 선택) — 보유/기본 양념/부족 표시와 안전 안내
9. 자정 배치가 임박·만료 재료를 알림함에 적재

## 4. 알고리즘 설명 포인트

- **일치율** = 보유한 필요 재료 종류 ÷ 필요 재료 종류. 같은 일치율이면 임박 재료를 쓰는 레시피 → 부족 종류가 적은 순 → 조리 시간이 짧은 순.
- 만료 재료 제외, 동의어(계란=달걀) 통일, 같은 재료 수량 합산, kg↔g·L↔ml 환산.
- **D-Day는 저장하지 않고 한국 날짜로 계산**해 배치가 실패해도 화면은 정확하고, 배치는 알림 대상 추출을 맡습니다.

## 5. 보안·안정성 포인트

- 토큰을 URL·localStorage에 두지 않음, Refresh 회전으로 탈취 감지, 사용자별 데이터 격리(타인 ID는 404).
- 이미지는 확장자가 아니라 파일 내용으로 검사(5MB), 파일명은 서버가 만든 UUID, 삭제·교체 시 파일 정리.
- AI 출력은 신뢰하지 않고 서버가 다시 검증(알레르기 재료 포함 시 거절), 요청 횟수 제한, 실패를 성공처럼 보이지 않음.

## 6. 기대 효과와 향후 과제

- 기대 효과: 음식물 낭비 감소, 유통기한 관리 편의, 장보기 전 재고 확인, 보유 재료 활용도 향상.
- 향후: 알림 발송(푸시·이메일), 사진으로 식재료 인식, 가족 공유, 폐기량·구매 통계, 공통 레시피 즐겨찾기.
