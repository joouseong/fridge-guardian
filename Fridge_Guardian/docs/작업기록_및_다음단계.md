## 5. 주의사항

- **`.env` / `.env.example`**
  - `.env`는 새로 만드는 파일이고 실제 비밀 값은 여기에만 둡니다. (지금은 없음, 단계 1에서 스크립트가 생성)
  - **`.env.example`은 빈 예시만.** 실제 키·비밀번호를 넣지 마세요. 나중에 GitHub에 올리면 그대로 공개됩니다.
  - **`.env.example`을 그대로 `.env`로 복사하지 말고**, 필요한 값만 넣으세요.
- **이전 Node 프로젝트(`freshfridge_capstone`)의 설정은 이 프로젝트와 변수 이름이 다릅니다.** 그대로 붙여넣지 마세요.
  | 이전(Node) | 이 프로젝트 |
  |---|---|
  | `PORT` | `SERVER_PORT` |
  | `DB_USER` | `DB_USERNAME` |
  | `DB_HOST`+`DB_PORT`+`DB_NAME` | `DB_URL` (JDBC 형식) |
  | `SESSION_SECRET` | 없음(JWT 사용, `JWT_SECRET`) |
  | `*_CALLBACK_URL` | 자동(Redirect URI만 콘솔에 등록) |
  | `GOOGLE_CLIENT_iD`(오타) | `GOOGLE_CLIENT_ID` |
  - **`DB_PASSWORD`는 이름이 같아서 그대로 읽힙니다.** 다른 값을 넣으면 로컬 MySQL 접속이 실패합니다.
- **팀원의 Aiven DB(캡스톤 데이터)에 이 프로젝트를 연결하지 마세요.** Flyway가 테이블을 만들어 기존 데이터와 충돌·혼합될 수 있습니다. 배포용 DB는 별도로 만드세요.
- **비밀 값 노출 이력:** 이번 작업 중 팀원이 준 키(Google/카카오 Secret, Aiven DB 비밀번호, 세션 시크릿)가 `.env.example`에 있었고 Claude 대화 기록에 표시됐습니다. 지금은 파일에서 삭제됐지만, 이 대화 기록이나 폴더를 공유·공개할 계획이면 **해당 키를 재발급**하세요.
- **로컬 데이터 보호:** `.local/mysql/data/`에 실제 회원·재고가 있습니다. 문제 해결을 이유로 초기화·삭제하지 마세요. PC의 기존 MySQL(3306)과 이 프로젝트 DB(3307)는 별개이며, 프로세스 이름만 보고 MySQL·Java를 모두 종료하지 마세요.
- **Git:** 이 폴더는 아직 Git 저장소가 아닙니다. 커밋하기 전 `.env`, `.local/`, 키, 로그, 빌드 결과, 업로드 사진이 제외되는지 확인하세요.
