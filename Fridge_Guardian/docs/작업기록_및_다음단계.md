### 3-10. 2026-09-30 늦은 작업 (`.env` 준비, 소셜 로그인 오류 진단, 팀원 비교 문서)
1. **`.env`가 이 Mac에 없던 이유**: `.env`는 Git 제외 파일이라 저장소에 딸려 오지 않음. 실제 키가 든 `.env`는 사용자의 다른 노트북·팀원 PC에 있음. 위치는 **`Fridge_Guardian/.env`(프로젝트 루트)**, 파일은 `chmod 600`, Git에서 제외됨(확인)
2. **키를 넣고 서버를 켰더니 DB 접속 실패** — 원인: `.env`에 `DB_USERNAME=`, `DB_PASSWORD=`가 **빈 값**으로 있어 기본값(`fridge_app`)을 덮어씀(`.env.example`을 통째로 복사한 결과). 두 줄을 `# DB_USERNAME=`처럼 주석 처리해 해결 → **빈 값 줄은 반드시 주석 처리**(원칙은 5번)
3. **서버는 키를 정상 인식**: `GET /api/auth/providers` → `{"google":true,"kakao":true}`, 로그인 요청이 제공자 화면까지 도달함. 서버가 보내는 Redirect URI를 확인함
   - Google: `http://127.0.0.1:5173/login/oauth2/code/google`
   - 카카오: `http://127.0.0.1:5173/login/oauth2/code/kakao`
4. **실제 로그인 시도 결과 — 두 제공자 모두 Redirect URI 미등록 오류**
   | 제공자 | 화면에 뜬 오류 | 뜻 |
   |---|---|---|
   | Google | `400 오류: redirect_uri_mismatch` (액세스 차단됨) | 클라이언트 ID에 위 주소가 등록되지 않음 |

## 5. 주의사항

- **`.env` / `.env.example`**
  - `.env`는 Git에 올라가지 않는 파일이고 실제 비밀 값은 여기에만 둡니다. 위치는 `Fridge_Guardian/.env`(현재 이 Mac에 있음, Google·카카오 키 저장됨, OpenAI 키는 비어 있음).
  - **값이 없는 줄은 `KEY=`로 비워 두지 말고 `# KEY=`로 주석 처리하세요.** 빈 값은 서버 기본값(DB 계정, 소셜 설정 등)을 덮어써 서버가 안 뜨거나 오류가 납니다.
  - **`.env.example`은 빈 예시만.** 실제 키·비밀번호를 넣지 마세요. 나중에 GitHub에 올리면 그대로 공개됩니다.
  - **`.env.example`을 그대로 `.env`로 복사하지 말고**, 필요한 값만 넣으세요.
- **이전 Node 프로젝트(`freshfridge_capstone`)의 설정은 이 프로젝트와 변수 이름이 다릅니다.** 그대로 붙여넣지 마세요.
  | 이전(Node) | 이 프로젝트 |
  |---|---|
  | `PORT` | `SERVER_PORT` |
  | `DB_USER` | `DB_USERNAME` |
  | `DB_HOST`+`DB_PORT`+`DB_NAME` | `DB_URL` (JDBC 형식) |
  | `SESSION_SECRET` | 없음(JWT 사용, `JWT_SECRET`) |
  | `*_CALLBACK_URL` | 자동(Redirect URI만 콘솔에 등록) |

- **로컬 데이터 보호:** `.local/mysql/data/`에 실제 회원·재고가 있습니다. 문제 해결을 이유로 초기화·삭제하지 마세요. PC의 기존 MySQL(3306)과 이 프로젝트 DB(3307)는 별개이며, 프로세스 이름만 보고 MySQL·Java를 모두 종료하지 마세요.

```bash
npm run dev        # DB(3307) + 백엔드(8080) + 프런트(5173). Ctrl+C로 백엔드·프런트 종료
```
